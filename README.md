# ⚡ ZENIX – Cinematic Voice AI Interface

ZENIX is a futuristic cinematic AI interface built using React, Framer Motion, and Tailwind CSS.  
It simulates a high-tech AI system boot sequence followed by an interactive energy core.

This project focuses on UI animation, motion design, and immersive frontend experience.

---

## 🚀 Features

### 🖥 Cinematic Boot Screen
- Animated system logs with progress bar
- CPU / Memory / Network status panel
- Holographic UI effects
- Rotating depth rings
- Scanline and grid overlay

### ⚡ Interactive Orb Core
- Multi-layer glowing energy core
- Dynamic phase states:
  - Idle
  - Listening
  - Processing
  - Responding
- Reactive energy visualizer bars
- Rotating orbital rings
- Particle burst effects
- Glitch animated text display

### 🎧 Audio Support
- Optional voice playback
- Safe autoplay handling
- Fallback message if autoplay blocked

### 🎨 Motion Design
- Built fully with Framer Motion
- Smooth transitions between screens
- Responsive layout
- High performance animation loops
